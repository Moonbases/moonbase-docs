---
title: Coinbase Commerce
description: Accept crypto payments with Coinbase Commerce.
---

<Steps>
  <Step>
    ### Create a Commerce wallet

    Sign up at [Coinbase Commerce](https://beta.commerce.coinbase.com/payments) and create a wallet.
  </Step>
  <Step>
    ### Set your business name

    Set it in [Settings → Business](https://beta.commerce.coinbase.com/settings/business). Without it, crypto checkouts fail.
  </Step>
  <Step>
    ### Copy your API key

    Create an API key in [Settings → Security](https://beta.commerce.coinbase.com/settings/security) and put it in `api/.env`:

    ```dotenv
    COINBASE_COMMERCE_API_KEY=...
    ```
  </Step>
  <Step>
    ### Add a webhook endpoint

    In [Settings → Notifications](https://beta.commerce.coinbase.com/settings/notifications), click **Add an endpoint** and use this URL:

    ```text
    https://<your API URL>/api/purchase/webhook/coinbase
    ```

    Enable the events in [Webhook events](#webhook-events), then copy the webhook shared secret into `api/.env`:

    ```dotenv
    COINBASE_COMMERCE_WEBHOOK_SECRET=...
    ```

    Crypto is offered at checkout only when both values are set. Restart the API.
  </Step>
</Steps>

## Webhook events

| Event | Required | What Moonbase does |
| --- | --- | --- |
| `charge:confirmed` | Yes | Delivers the order. |
| `charge:failed` | Yes | Marks the order failed, releases its discount code and store credit, and tells the customer the payment failed. |
| `charge:delayed` | Yes | The customer paid after the charge expired. Marks the order pending and keeps its discount code and store credit reserved until you decide. Nothing is delivered yet, and the customer gets no failure email. |
| `charge:resolved` | Yes | You resolved a late or unresolved charge in Coinbase Commerce: delivers the order. |
| `charge:pending` | Optional | Keeps the discount code and store credit reserved while the payment confirms on the blockchain. |

## Good to know

- Coinbase sends `charge:delayed` when a payment arrives after the charge expired, and the API log names the charge. Check it in Coinbase Commerce: **Resolve** it to deliver the order (Coinbase sends `charge:resolved`), or refund it there.
- Coinbase refunds and disputes don't reach Moonbase. If you refund a crypto payment, use **Revoke access** on the order in **Dashboard → Orders**.
- Crypto payments are always one-time and never get tax from Stripe Tax.

<Callout type="info" title="Public endpoint required">
  Coinbase must be able to reach the webhook URL over the internet. Use your public HTTPS API address, not `localhost`.
</Callout>
