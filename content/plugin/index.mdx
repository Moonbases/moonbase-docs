Moonbase ships with two plugin runtimes: a backend loader for the API and a frontend runtime for the Next.js storefront and dashboard. Backend plugins are JavaScript files the API loads from disk at startup. Frontend plugins are compiled into the app and registered explicitly.

<Callout type="warn" title="Upgrading from 1.8?">
  Moonbase 2.0 runs on Express 5 and Mongoose 9 and has a redesigned UI. Plugins written for 1.8 need checking before you enable them again: follow [Migrating plugins from 1.8](/docs/plugin/migrating).
</Callout>

</Callout>

## Two runtimes
<Tabs items={['Backend runtime', 'Frontend runtime']} defaultIndex={0}>
  <Tab>
    - Backend plugins run inside the API. They can add routes, guard or extend the checkout API, use the Mongoose models, patch payment services, and react to fulfilled purchases.
  </Tab>
  <Tab>
    - Frontend plugins run in the browser. They can render UI in slots (everywhere, or in the dashboard sidebar), add dashboard pages, call the API through the app's proxy, and stop a checkout with guards.
  </Tab>
</Tabs>

<Callout type="info" title="Pick the right runtime">
  Choose the backend for data, rules and workflows, and the frontend for UI and flow. Anything that must be enforced belongs in the backend.
</Callout>
